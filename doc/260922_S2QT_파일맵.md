# S2QT 파일맵 · 2026-09-22 기준

> **용도** — 앞으로의 검토·작업지시서가 매번 구조를 다시 조사하지 않도록, 흐름별로 "어디를 열어야
> 하는가"를 고정한 문서입니다. 작업별 파일맵(각 작업지시서 안)은 **변경할 파일**을 적고, 이 문서는

```
(v1.0, QT만     (장년 전용 설교요약)    (사람 입력 확정된 JSON 전문)
```

> **DOCX·PPTX는 현재 산출물이 아닙니다.** `qtstep3_service.go`가 요청을 받아도
> `"DOCX 생성은 아직 연결되지 않았습니다."`를 돌려줍니다. `temp.docx` / `temp.pptx` /
> `temp_office_*.json`이 `var/temp/`에 보인다면 앱이 만든 것이 아닙니다(§10-8 참조).

**핵심 불변식 세 가지**

1. `temp.json`의 `version`은 **항상 `"1.0"`** 입니다. LLM 원본만 `1.1`(infographic 포함)이고,
   그것은 파일로 저장되지 않습니다.
2. **작업내역 DB 저장은 Step1에서만** 합니다. Step2는 DB를 건드리지 않습니다.
3. **시리즈는 항상, 제목은 장년만** 화면 입력값이 우선합니다. LLM이 메타정보를 날조한 사례가 있어
   내린 결정입니다(비장년 제목은 LLM이 연령대에 맞게 새로 짓습니다).


이 파일에 모여 있는 공용 헬퍼(다른 서비스도 씁니다):

| 헬퍼 | 하는 일 |
|---|---|
| `getStringFromMap` / `getStringSliceFromMap` | metadata에서 안전하게 꺼내기 (`[]any`·쉼표문자열 모두 수용) |
| `copyMetadata` | metadata 맵 얕은 복사. **맵은 참조 타입** — 한쪽에만 키를 더할 때 필수 |
| `getInfographicFromMap` | `*InfographicData` / `map[string]any` 어느 쪽이든 재마샬로 통일 |
| `cleanStringSlice` | 트림 + 빈 값 제거 + **중복 제거** |
| `normalizeBibleReference` / `normalizeBibleRefSlice` | 성구 표기 정규화(`살전` → `데살로니가전서`) |
| `ensureQTTitlePrefix` | `[QT]` 접두어 보장 |

## 8. DB 스키마 — 3 테이블

```sql
app_settings     (setting_key PK, setting_value, value_type, is_secret, setting_group, updated_at)
history_master   (id PK, title, bible_text, hymn, preacher, church_name, sermon_date, created_at, updated_at)
history_qt_json  (id PK, history_id FK, audience, qt_result_json, created_at, updated_at)
```

> ### ⚠ `InitSQLite`에는 `ALTER TABLE` 경로가 없습니다
> `CREATE TABLE IF NOT EXISTS`만 있으므로 **기존 사용자의 DB에 컬럼을 추가할 방법이 없습니다.**
> 스키마 변경은 마이그레이션 코드를 새로 짜야 하는 큰 작업입니다. 지금까지의 기능 확장은 모두
> 이것을 피해서 설계했습니다.

**설계 결정 두 가지**

- `history_master.title`은 시리즈와 제목을 `|||`로 합친 라벨입니다. `-`와 `—`는 설교 제목에 실제로
  등장하므로 쓸 수 없습니다. `buildHistoryTitle` / `splitHistoryTitle`
  ([qtstep1_service.go](../service/qtstep1_service.go))로만 다루고, 화면에서는 나눠서 표시합니다.
- 작업내역은 **INSERT-only**입니다. 같은 설교를 여러 번 저장하면 이력이 여러 건 쌓이며,
  이는 의도된 스냅샷입니다. 정리는 사용자가 직접 삭제로 합니다.

## 10. 지뢰

1. **저장소 전체가 CRLF**이고 `.gitattributes`가 없습니다. `gofmt -l`은 거의 모든 파일을
   지적합니다. **`gofmt -w`를 일괄 실행하지 마십시오.** 새로 만든 LF 파일만 포맷합니다.
2. **Go 맵은 참조 타입**입니다. `qt := doc.QTSectionDoc`는 얕은 복사라 `Metadata`가 같은 맵을
   가리킵니다. 한쪽에만 키를 더하려면 `copyMetadata()`를 거치십시오.
3. **`cleanStringSlice`는 중복을 제거합니다.** 테스트에서 같은 문자열 N개로 개수를 맞추면 실패합니다.
4. **`SaveHtmlAndMakeJSON()`은 죽은 코드**입니다. HTML에서 temp.json을 덮어쓰는 유일한 경로였습니다.
5. **`prompt_infographic.go` / `var/conf/prompt_infographic.md`는 코드에서 참조하지 않습니다.**
   작성 규칙 참고용입니다.
6. **LLM은 메타정보를 날조합니다.** 2026-08-29 테스트에서 5개 모델 중 3개(유료 Claude 포함)가
   설교자·교회명 등을 지어냈습니다. 화면 입력이 언제나 우선입니다.
7. **큰 파일**: `pdf_service.go`(1526) · `template_service.go`(1065) · `png_service.go`(1023) ·
   `util_service.go`(955) · `app.css`(2162) · `settingsBasicTab.js`(947). 전체 읽기 전에
   Grep으로 범위를 좁히십시오.
8. **`var/temp/`에 예상 밖의 파일이 보이면 `go test`를 의심하십시오.**
   `word_test.go` / `ppt_test.go`는 실제 `../var/temp/temp.json`을 읽고 같은 폴더에
   `temp.docx` · `temp.pptx` · `temp_office_*.json`을 만들었습니다. 2026-09-22에
