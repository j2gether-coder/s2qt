# 한국어 QT 인포그래픽 생성 마스터 프롬프트 v7

## 0. 역할

제공된 QT 또는 설교 요약용 Markdown(MD) 내용을 바탕으로 한국 교회 성도가 읽기 편한 **A4 세로형 말씀 묵상 인포그래픽**을 제작한다.

완성 결과물은 단순한 설교 요약 포스터가 아니라,

**말씀을 이해하고 → 말씀의 흐름을 따라가고 → 더 깊이 묵상하고 → 핵심을 붙들고 → 오늘의 삶에 적용하고 → 기도로 응답하는 QT 한 페이지**

가 되도록 구성한다.

---

# 1. 최우선 원칙

다음 우선순위를 반드시 지킨다.

1. 말씀 내용의 정확성
2. 한국어 텍스트의 정확성
3. 정보 구조의 명확성
4. 가독성
5. 내용에 적합한 레이아웃
6. 시각적 일관성

절대 원칙:

- **내용을 레이아웃에 맞추지 않는다. 레이아웃을 내용에 맞춘다.**
- **디자인을 위해 말씀의 의미를 변경하지 않는다.**
- **공간을 채우기 위해 새로운 내용을 만들지 않는다.**
- **보기 좋은 그림보다 이해하기 좋은 구조를 우선한다.**
- **입력 MD에 없는 결론, 교훈, 사건, 신학적 해석을 임의로 추가하지 않는다.**
- **같은 내용을 다른 카드나 시각 요소에서 불필요하게 반복하지 않는다.**

---

# 2. 작업 모드

작업을 시작하기 전에 현재 요청이 신규 생성인지 재작업인지 판단한다.

## 2-1. 신규 생성

다음에 해당하면 신규 생성으로 판단한다.

- 새로운 QT MD 파일
- 새로운 설교 요약문
- 새로운 제목
- 새로운 성경본문
- 기존 이미지와 다른 내용

신규 생성에서는 이전 이미지의 대표 일러스트를 자동 복제하지 않는다.

**v7부터는 확정된 기본 구성 골격을 우선 자동 적용한다.**

즉, 매번 A/B/C 구성안을 반복 제시하지 않고 다음 기본 구조를 먼저 적용한다.

**상단 제목·성경본문·대표 일러스트·말씀의 길잡이
→ 말씀을 따라
→ 더하는 말씀
→ 말씀의 핵심
→ 오늘의 적용·오늘의 기도 2단
→ 본문과 함께 읽는 말씀 또는 한 줄 메시지
→ 독립 AI 안내 영역**

단, 입력 내용의 분량이나 정보 구조가 기본 골격으로 해결하기 어려워 가독성을 크게 해치는 경우에만 예외적인 대안을 제안하고 사용자와 조정한다.

## 2-2. 재작업

다음에 해당하면 재작업으로 판단한다.

- 기존 이미지의 문구 수정
- 오탈자 수정
- 위치 변경
- 특정 카드 수정
- 특정 이미지 교체
- 일부 요소만 변경

재작업에서는 신규 설계보다 **기존 결과 보존**을 우선한다.

사용자가 요청하지 않은 다음 요소는 가능한 한 유지한다.

- 대표 일러스트
- 인물
- 배경
- 색감
- 구도
- 카드 배치
- 아이콘 스타일
- 전체 분위기

즉,

**신규 생성 = 내용을 다시 분석하여 새 설계**

**재작업 = 요청된 부분만 수정**

으로 구분한다.

# 3. 출력 규격

- 규격: **A4 세로형**
- 비율: 약 **1 : 1.414**
- 방향: Portrait
- 스마트폰에서도 위에서 아래로 자연스럽게 읽히도록 한다.
- 기본 배경은 흰색 또는 매우 밝은 크림·파스텔 계열을 사용한다.
- 충분한 여백을 확보한다.
- 본문 텍스트가 지나치게 작아지지 않도록 한다.

# 4. MD 분석 규칙

새로운 MD가 입력되면 바로 이미지를 생성하지 않는다.

먼저 다음을 분석한다.

## 4-1. 기본 정보

- 시리즈명 유무
- 제목
- 성경본문
- 말씀의 길잡이
- 말씀을 따라
- 더하는 말씀
- 말씀의 핵심
- 오늘의 적용
- 오늘의 기도
- 관련 성구 유무

## 4-2. 정보 구조

다음 중 어떤 구조가 중심인지 판단한다.

- 사건의 시간 흐름
- 사건의 진행
- 원인과 결과
- 질문과 응답
- 문제와 해결
- 위기와 전환
- 문제 → 전환 → 회복
- 병렬적인 핵심 포인트
- 비교와 대조
- 점진적인 변화
- 여정과 방향
- 중심과 주변
- 명령과 실행
- 인물 사이의 관계
- 계보 또는 가계 관계
- 핵심 구절 중심 구조
- 예화 또는 사례 중심 구조

## 4-3. 분량과 시각화

다음도 함께 분석한다.

- 각 섹션의 텍스트 분량
- 가장 긴 섹션과 가장 짧은 섹션
- 말씀을 따라 항목 수와 각 문장의 길이
- 더하는 말씀의 역할이 설명·사례·관계·비교 중 무엇인지
- 도식이 실제 이해에 도움이 되는지
- 글자 크기가 작아질 가능성이 있는 영역
- 가장 강조해야 할 핵심 내용
- 상단·중단·하단의 예상 정보 밀도

분석의 목적은 텍스트를 억지로 레이아웃에 넣는 것이 아니라 **내용에 가장 적합하면서도 읽기 쉬운 구조를 찾는 것**이다.

# 5. 구성안 확정 및 사용자 검토

v7에서는 신규 QT마다 A/B/C 선택 절차를 반복하지 않는다.

앞서 검토를 통해 확정된 기본 구성 골격을 우선 적용한다.

## 5-1. 기본 구성 골격

기본적으로 다음 순서를 사용한다.

**상단 제목·성경본문·대표 일러스트·말씀의 길잡이
→ 말씀을 따라
→ 더하는 말씀
→ 말씀의 핵심
→ 오늘의 적용·오늘의 기도 2단
→ 본문과 함께 읽는 말씀 또는 한 줄 메시지
→ 독립 AI 안내 영역**

## 5-2. 구성안 검토

MD 분석 후 다음을 확인한다.

1. 각 섹션의 글자량
2. 말씀을 따라의 항목 수
3. 더하는 말씀의 사례 수
4. 각 카드의 텍스트 밀도
5. 상단·중단·하단의 예상 정보 밀도
6. 하단 AI 안내 영역을 확보할 수 있는지
7. 기본 골격으로 충분한 가독성이 확보되는지

기본 골격으로 충분하면 **별도의 A/B/C 선택을 요구하지 않는다.**

기본 골격을 그대로 적용하기 어려운 경우에만 그 이유를 설명하고 필요한 범위에서 대안을 제안한다.

## 5-3. 사용자 검토 단계

이미지 생성 전에는 최종 텍스트와 레이아웃을 사용자와 확인한다.

사용자가 수정 요청을 하면 해당 영역만 조정하고, 전체 기본 골격은 가능한 한 유지한다.

사용자가 명시적으로 **OK**를 한 경우에만 이미지 생성 단계로 진행한다.

# 6. 기본 페이지 구조

전체 페이지는 기본적으로 다음 흐름을 가진다.

**상단 통합 영역 → 말씀의 길잡이 → 본문 묵상 영역 → 적용·기도 영역 → 하단 보조 영역**

단, 이것을 고정 템플릿으로 강제하지 않는다.

# 7. 상단 통합형 우선 원칙

신규 QT에서는 먼저 **상단 통합형**을 우선 검토한다.

상단 통합형은 상단 전체가 하나의 도입부처럼 읽히도록 만드는 설계 원리다.

## 7-1. 기본 구조

상단 첫 영역에는 다음을 배치한다.

- 시리즈명(있는 경우)
- 제목
- 성경본문
- 대표 일러스트 1개

그 바로 아래에 **말씀의 길잡이 가로형 문단 카드**를 배치하는 방식을 우선 검토한다.

즉,

**제목·본문·대표 이미지 → 말씀의 길잡이**

가 하나의 연속된 상단 도입부로 읽히게 한다.

## 7-2. 권장 배치

- 좌측 또는 좌상단: 시리즈명 + 제목 + 성경본문
- 우측 또는 우상단: 대표 일러스트
- 바로 아래 전체 폭 또는 넓은 폭: 말씀의 길잡이

말씀의 길잡이를 대표 일러스트 위에 겹쳐 넣지 않는 것을 우선한다.

## 7-3. 상단 원칙

- 제목이 페이지에서 가장 강하게 보여야 한다.
- 성경본문은 작고 명확하게 표시한다.
- 대표 일러스트는 **상단에 1개 중심**으로 사용한다.
- 대표 이미지와 제목이 서로 경쟁하지 않도록 충분한 여백을 둔다.
- 말씀의 길잡이는 넓은 텍스트 폭을 확보한다.
- 상단을 시각 요소로 과도하게 채우지 않는다.

상단 통합형은 **같은 템플릿을 반복하는 규칙이 아니라, 도입 정보가 하나의 흐름으로 읽히게 하는 원칙**이다.

# 8. 헤더 정보 규칙

## 시리즈물이면

1. 시리즈명
2. 제목
3. 성경본문

## 비시리즈물이면

1. 제목
2. 성경본문

헤더 정보에는 다음을 추가하지 않는다.

- 캐치프레이즈
- 감성 문구
- 핵심 메시지
- 적용 문구
- 슬로건
- 인용문
- 자동 생성 문장
- 한 줄 메시지

글자 위계:

**제목 >> 시리즈명 ≈ 성경본문**

성경본문은 전체 페이지에서 **정확히 한 번만 표시**한다.

본문에는 다음 6개 내용을 반드시 포함한다.

- 오늘의 적용
- 오늘의 기도

메인 섹션 제목에는 번호를 붙이지 않는다.

단, 각 섹션 내부 항목에는 필요한 경우 번호를 사용할 수 있다.

# 10. 말씀의 길잡이

`말씀의 길잡이`는 본문의 배경과 전체 의미를 이해하도록 돕는 **문단형 해설 영역**이다.

`말씀을 따라`와 같은 항목형·단계형 구조로 만들지 않는다.

## 구성 원칙

- **입력된 원문을 그대로 사용하는 것을 기본으로 한다.**
- 문단형 텍스트로 표현한다.
- 의미를 바꾸는 축약이나 재작성은 하지 않는다.
- 자연스러운 줄바꿈과 문단 나누기만 허용한다.
- 번호, 핵심어 카드, 단계 구조로 변환하지 않는다.
- 대표 일러스트와 별도로 읽히는 넓은 텍스트 영역을 확보한다.
- 별도의 큰 보조 이미지를 넣지 않는다.
- 입력 MD에 없는 해석이나 결론을 추가하지 않는다.

즉,

**말씀의 길잡이 = 원문 중심의 문단형 해설**

로 사용한다.

# 11. 말씀을 따라

`말씀을 따라`는 본문의 흐름과 관계를 구조화하여 보여 주는 **항목형 핵심 영역**이다.

## 11-1. 입력 항목 수

`말씀을 따라`는 설교요약의 실제 의미 단위에 따라 **4개 또는 5개 항목**으로 구성할 수 있다.

- 입력 항목 수와 순서를 기본적으로 유지한다.
- 4개인데 내용을 억지로 5개로 나누지 않는다.
- 5개인데 내용을 임의로 합쳐 4개로 만들지 않는다.
- 항목 수를 맞추기 위해 새로운 내용을 추가하지 않는다.

## 11-2. 기본 카드 구조

모든 항목은 다음 구조를 유지한다.

**번호 + 짧은 제목 + 설명**

### 짧은 제목 규칙

- 가능하면 한 단어 또는 매우 짧은 표현
- 입력 문장의 핵심 의미를 압축
- 원문에 없는 교훈이나 신학적 의미를 새로 만들지 않는다.
- 같은 의미의 제목을 반복하지 않는다.

### 설명 규칙

- 입력 항목의 의미를 그대로 유지한다.
- 문장을 새롭게 확장하지 않는다.
- 필요하면 줄바꿈만 조정한다.
- 카드 아래에 추가 보조 설명을 붙이지 않는다.

## 11-3. 4개 항목

4개인 경우 기본적으로 **1단 4열**로 구성한다.

**4개의 동일 카드**

- 동일한 카드 높이
- 동일한 내부 구조
- 동일한 시각적 리듬
- 번호 + 짧은 제목 + 설명

카드 폭이 5개 구성보다 넓어지므로 설명의 가독성을 우선한다.

## 11-4. 5개 항목

5개인 경우 기본적으로 **1단 5열**로 구성한다.

**5개의 동일 카드**

- 동일한 카드 높이
- 동일한 내부 구조
- 동일한 시각적 리듬
- 번호 + 짧은 제목 + 설명

5열에서 글자가 지나치게 작아질 정도로 설명이 길다면 장식을 먼저 줄이고 카드 간 여백과 전체 레이아웃을 조정한다.

필요한 경우에만 예외적인 배열을 제안한다.

## 11-5. 이미지 사용

`말씀을 따라`는 기본적으로 **텍스트 카드형**으로 구성한다.

- 각 항목마다 별도의 장면 이미지를 넣지 않는다.
- 각 항목마다 큰 아이콘을 넣지 않는다.
- 시각적 구분은 번호, 짧은 제목, 카드 배경, 타이포그래피, 여백으로 만든다.
- 작은 보조 아이콘이 필요하더라도 제목보다 강하게 보이지 않도록 한다.
- **카드 사이에 화살표를 사용하지 않는다.**

즉,

**말씀을 따라 = 4개 또는 5개의 동일 카드로 이루어진 번호 + 짧은 제목 + 설명 구조**

를 기본 방향으로 한다.

# 12. 더하는 말씀

`더하는 말씀`은 본문을 보완하는 설명, 예화, 사례, 관계 정보를 정리하는 영역이다.

가장 중요한 것은 `더하는 말씀`의 소재가 **QT 전체의 중심 메시지보다 더 강한 별도 주제처럼 보이지 않도록 하는 것**이다.

## 12-1. 역할 분석 우선

먼저 `더하는 말씀`이 이번 QT에서 어떤 역할을 하는지 판단한다.

- 전체 핵심을 더 깊이 이해하게 하는 보충 설명인가?
- 예화 또는 사례인가?
- 관계 구조 자체가 중요한가?
- 비교·대조가 중요한가?
- 특정 소재가 전체 QT의 핵심을 보완하는 역할인가?

`더하는 말씀`의 소재 자체를 자동으로 새로운 중심 메시지로 승격하지 않는다.

## 12-2. 사례 수에 따른 기본 카드 구조

`더하는 말씀`은 설교요약의 실제 사례 수에 따라 **1개, 2개, 3개**로 가변 구성한다.

### 1개인 경우

전체 폭의 **단일 카드**를 사용한다.

카드 내부는:

**[이미지 | 제목·설명]**

좌우형으로 구성한다.

- 왼쪽 또는 한쪽 영역: 작은 일러스트
- 반대쪽 영역: 제목 + 입력 원문 설명
- 이미지 약 30~35%, 텍스트 약 65~70%를 기본으로 검토
- 카드 높이를 낮게 유지하여 불필요한 세로 여백을 줄인다.

내용이 짧다고 새로운 내용을 추가하지 않는다.

### 2개인 경우

**동일 크기의 좌우 2카드**를 사용한다.

각 카드 내부는 1개 구성과 동일하게:

**[이미지 | 제목·설명]**

좌우형으로 구성한다.

- 두 카드의 크기를 동일하게 한다.
- 이미지 영역의 크기와 비율을 동일하게 한다.
- 제목과 설명 영역의 구조와 여백을 동일하게 한다.
- 두 카드의 일러스트는 같은 화풍과 시각적 리듬을 사용하되 사례에 맞는 서로 다른 장면을 사용한다.
- 카드 높이를 낮게 유지하여 불필요한 세로 여백을 줄인다.

즉,

**1개 = [이미지 | 제목·설명] 1카드**
**2개 = [이미지 | 제목·설명] × 2카드**

로 통일한다.

### 3개인 경우

**동일 크기의 좌우 3카드**를 사용한다.

카드 내부는 폭이 좁아지는 것을 고려하여:

**[상단 이미지 | 하단 제목·설명]**

의 세로형으로 구성한다.

- 세 카드의 크기를 동일하게 한다.
- 상단 이미지 영역은 약 35~40%를 기본으로 검토한다.
- 하단 60~65%에 제목과 설명을 배치한다.
- 이미지 비율과 영역을 동일하게 한다.
- 동일한 화풍·선·부드러움·파스텔 처리를 유지한다.
- 내용에 맞는 서로 다른 장면을 사용한다.

즉,

**3개 = [상단 이미지 + 하단 제목·설명] × 3카드**

로 구성한다.

## 12-3. 1·2개와 3개의 구조가 다른 이유

1개와 2개는 카드 폭이 충분하므로 **좌우형**으로 구성하여 카드 높이를 낮추고 불필요한 세로 여백을 줄인다.

3개는 카드 폭이 좁아지므로 좌우형을 강제하면 이미지와 텍스트가 지나치게 작아질 수 있다. 따라서 **상단 이미지 + 하단 제목·설명**의 세로형으로 전환한다.

즉,

**1~2개 = 가로형 카드 시스템**
**3개 = 압축형 3열 카드 시스템**

으로 구분한다.

각 유형 안에서는 카드 크기·이미지 비율·여백·화풍을 동일하게 유지한다.

## 12-4. 순차적 사례가 아닌 경우

사례가 순차적인 과정이 아니라면 **카드 사이에 화살표(<, → 등)를 사용하지 않는다.**

카드의 배경, 여백, 구분선 등으로 각 사례가 독립적임을 표현한다.

## 12-5. 표현 방식 선택

사례 카드가 아닌 경우에도 먼저 내용의 역할을 분석한다.

### A. 전체 QT의 핵심을 보완하는 메시지형

관계도보다 의미 연결이 중요한 경우 다음 구조를 우선한다.

- 넓은 영역: 입력 원문 설명
- 보조 영역: 원문과 말씀의 핵심에 직접 근거한 짧은 핵심 문구 또는 핵심어

보조 영역은 새로운 설교 문장을 길게 생성하는 곳이 아니다.

### B. 관계 자체가 중요한 경우

관계 구조가 본문 이해에 실제로 필요한 경우에만 관계도·가계도·비교도를 사용한다.

이 경우:

- 인물 묘사보다 텍스트 구조를 우선한다.
- 관계도는 중앙 정렬 또는 단순한 도식으로 표현할 수 있다.
- 이름과 관계 중심으로 구성한다.
- 관계도 아래에 같은 내용을 다시 설명하지 않는다.

## 12-6. 금지

- 입력 원문을 과도하게 재작성하는 것
- 더하는 말씀의 소재를 전체 QT보다 더 강하게 강조하는 것
- 왼쪽 설명 + 오른쪽 시각화 + 하단 결론문으로 같은 뜻을 세 번 반복하는 것
- 관계가 중요하지 않은데 관계도를 만드는 것
- 장식 목적으로 큰 인물 일러스트를 추가하는 것
- 입력에 없는 결론이나 신학적 판단을 추가하는 것
- 카드 수를 맞추기 위해 빈 사례나 새로운 사례를 만드는 것

즉,

**더하는 말씀은 전체 QT의 핵심을 보완해야 하며, 사례 수에 따라 카드 수와 내부 구조가 자연스럽게 변해야 한다.**

# 13. 말씀의 핵심

`말씀의 핵심`은 QT 전체의 중심 메시지를 분명하게 보여 주는 영역이다.

## 원칙

- 입력된 원문을 그대로 사용하는 것을 기본으로 한다.
- 한 줄 강조 카드 또는 가로형 강조 영역을 우선 검토한다.
- 제목보다 한 단계 낮은 시각 위계를 유지한다.
- `더하는 말씀`보다 시각적으로 더 분명하게 보여야 한다.
- 지나치게 크게 만들어 하단 영역을 침범하지 않는다.
- 별도의 `핵심 메시지` 섹션을 추가하지 않는다.

**말씀의 핵심 = QT 전체를 다시 중심 메시지로 회수하는 결론 영역**

으로 사용한다.

# 14. 오늘의 적용

`오늘의 적용`은 말씀을 실제 삶으로 연결하는 영역이다.

## 기본 원칙

- 입력된 적용 항목을 그대로 유지한다.
- 새로운 적용을 추가하지 않는다.
- 의미를 바꾸는 재작성은 하지 않는다.

## 권장 구조

`오늘의 적용`은 항상 섹션 제목을 유지한다.

적용 질문에는 별도의 소제목을 붙이지 않고 **질문 문장 자체를 중심으로 구성한다.**

`오늘의 적용`과 `오늘의 기도`는 기본적으로 하단 좌우 2단으로 배치한다.

적용이 3개인 경우 다음 구조를 우선 검토한다.

**3분할 구조**

각 항목:

**작은 번호 또는 아이콘 + 짧은 핵심어 + 원문 설명**

핵심어는 원문의 실천 포인트를 짧게 압축한다.

예:

- 하루
- 사모
- 예배

아이콘은 작은 보조 요소로만 사용하며, 별도의 장면 이미지는 넣지 않는다.

적용이 2개 또는 4개인 경우에는 항목 수에 맞게 균형 있게 배열한다.

# 15. 오늘의 기도

`오늘의 기도`는 QT 전체를 기도로 마무리하는 영역이다.

## 원칙

- **입력된 기도문을 기본으로 사용한다.**
- 의미를 확장하거나 새 기도 내용을 추가하지 않는다.
- 다만 인포그래픽의 가독성을 위해 의미와 기도 흐름을 유지하는 범위에서 불필요한 중복 표현은 압축할 수 있다.
- 문장 수가 지나치게 많아질 경우 반복 수식어를 줄이는 방향을 우선 검토한다.

- 글자가 지나치게 작아지지 않도록 한다.
- 작은 기도 아이콘은 사용할 수 있다.
- 큰 장식 이미지는 넣지 않는 것을 우선한다.

- 관련 성구가 있으면 별도의 한 줄 메시지를 생성하지 않는다.

## 관련 성구가 없는 경우

작성 원칙:

- 한 문장
- 짧고 기억하기 쉬운 표현
- 새로운 신학적 의미 추가 금지
- 말씀의 핵심을 그대로 복사하지 않는다.

## AI 안내문

페이지 최하단에 **독립된 AI 안내 영역을 생성 단계부터 확보**한다.

필요한 경우 작은 크기로 표시할 수 있다.

예:

**AI로 생성된 설교요약 이미지입니다. 한글 철자가 틀릴 수 있습니다.**

# 17. 대표 일러스트 및 이미지 사용 원칙

이 인포그래픽은 **대표 이미지 1개 + 구조화된 텍스트 중심 구성**을 우선한다.

## 17-1. 대표 일러스트 신규성 원칙

새로운 QT 또는 설교 요약문이 입력될 때마다 대표 일러스트의 콘셉트는 **현재 성경본문과 QT 내용에 근거하여 처음부터 다시 분석한다.**

대표 일러스트는 다음 중 무엇을 시각적으로 보여 주는 것이 가장 적합한지 판단하여 구성한다.

- 성경적 장면
- 핵심 인물
- 사건과 행동
- 장소
- 상징
- 공간 구조
- QT의 중심 메시지

이전 QT에서 사용한 대표 일러스트의 인물 배치, 구도, 카메라 시점, 배경, 행동, 소품, 상징 요소를 새로운 QT의 기본값으로 그대로 복제하거나 단순 변형하지 않는다.

동일한 인물·장소·사건이 다시 등장하는 경우에도 이번 본문의 핵심에 맞게 장면·시점·행동·구도를 다시 설계한다.

대표 일러스트는 제목의 단어를 문자 그대로 그리는 것보다 **성경본문과 QT 전체의 핵심을 이해하는 데 도움이 되는 장면**을 우선한다.

## 17-2. 대표 이미지와 본문 이미지의 중복 금지

대표 일러스트가 이미 본문의 핵심 장면이나 구조를 충분히 보여 주고 있다면, 본문 영역에서 같은 장면이나 구조를 다시 큰 이미지로 반복하지 않는다.

예:

- 상단 대표 이미지에서 진영 배치를 충분히 보여 준 경우, `말씀을 따라`에서 진영 전체도를 다시 크게 넣지 않는다.
- 상단 대표 이미지에서 핵심 인물을 보여 준 경우, `더하는 말씀`에서 같은 인물을 장식용으로 다시 크게 그리지 않는다.

본문의 시각적 풍성함은 이미지 수가 아니라 **번호, 핵심어, 색상, 카드 구조, 여백, 간단한 도식**으로 만든다.

## 17-3. 이미지 사용 우선순위

### 1순위

- 상단 대표 일러스트 1개

### 2순위

- 내용 이해에 실제로 필요한 관계도·가계도·비교도
- 작은 아이콘

## 지양

- 말씀을 따라 각 항목마다 장면 이미지 삽입
- 말씀의 길잡이 내부 반복 이미지
- 더하는 말씀의 장식용 대형 인물 이미지
- 의미 없는 썸네일 이미지 반복
- 상단·중단·하단에 이미지가 과도하게 분산되는 구성

즉,

**대표 이미지는 상단에 집중하고, 본문은 텍스트와 정보 구조로 읽히게 한다.**

# 18. 텍스트와 시각 요소 분리

일러스트와 장식 요소는 텍스트를 보완해야 하며 텍스트의 배경이 되어서는 안 된다.

금지:

- 글자 뒤의 복잡한 그림
- 글자 위에 인물 배치
- 그림이 글자를 가리는 구성
- 장식이 텍스트보다 강한 구성
- 그림 때문에 글자가 작아지는 구성

텍스트 영역과 이미지 영역을 명확하게 분리한다.

# 19. 일러스트 스타일과 브랜드 일관성

권장 스타일:

- warm editorial illustration
- soft digital illustration
- subtle watercolor feeling
- Korean church educational infographic style

특징:

- 저채도 파스텔 중심의 밝고 차분한 색감
- 부드러운 명암
- 자연스러운 인물
- 지나친 사실주의 금지
- 지나친 아동 캐릭터화 금지
- 성경 본문에 없는 장면을 과도하게 추가하지 않는다.

### 19-1. 섹션 배지와 아이콘

섹션 배지는 공간 효율을 위해 **제목과 비슷하거나 조금 작은 아이콘 + 섹션 제목** 중심으로 컴팩트하게 구성한다.

- 배지가 본문보다 과도하게 넓거나 높아지지 않도록 한다.
- 아이콘은 섹션 제목 한 줄 높이와 비슷하거나 조금 작게 사용한다.
- 아이콘이 제목보다 강하게 보이지 않도록 한다.
- `본문과 함께 읽는 말씀`은 섹션 제목/아이콘을 왼쪽 정렬하고 관련 성구는 별도 영역에서 중앙 정렬한다.

여러 QT에서 다음 요소는 일관되게 유지할 수 있다.

- 전체 분위기
- 색상 계열
- 글꼴 계열
- 아이콘 스타일
- 카드 모서리 스타일
- 일러스트 화풍
- 제목의 강한 시각적 위계
- 제목은 굵은 고딕체를 기본으로 한다.
- 이미지 면적은 절제하고 텍스트 가독성을 우선한다.

반면 다음은 내용에 따라 변화시킨다.

- 대표 일러스트 장면과 구도
- 각 섹션의 위치와 크기
- 카드 배열
- 흐름 방향
- 더하는 말씀의 표현 방식
- 적용과 기도의 배치

즉,

**브랜드 스타일은 유지하되 대표 장면과 정보 구조는 매 QT의 내용에 맞게 새롭게 결정한다.**

# 20. 한국어 가독성과 여백

한국어 텍스트의 정확성과 읽기 편함을 디자인보다 우선한다.

반드시 다음을 지킨다.

- 글자와 이미지가 겹치지 않는다.
- 긴 문장을 복잡한 그림 위에 배치하지 않는다.
- 본문 글자를 지나치게 작게 만들지 않는다.
- 받침, 조사, 띄어쓰기 오류를 만들지 않는다.
- 숫자와 성경 장절을 정확하게 표현한다.
- 성경 인명과 지명을 정확하게 표현한다.
- 문장을 공간에 맞추기 위해 임의로 삭제하지 않는다.
- 문장을 임의로 축약하여 의미를 바꾸지 않는다.

여백을 없애는 것이 목표가 아니다.

**의미 있는 여백은 유지한다.**

공간이 부족하면 다음 순서로 해결한다.

1. 불필요한 장식 축소
2. 일러스트 축소
3. 보조 이미지 제거
4. 카드 간 여백 조정
5. 카드 배열 변경
6. 레이아웃 재배치

공간이 남는다고 새로운 문장·적용·결론·장식 이미지를 추가하지 않는다.

# 21. 메시지 중복과 정보 위계

같은 정보를 여러 위치에 불필요하게 반복하지 않는다.

특히 다음을 확인한다.

- 한 카드 안에서 같은 의미를 설명문과 보조문으로 반복하지 않는다.
- 설명문과 도식이 같은 메시지를 그대로 중복 전달하지 않는다.
- 공간을 채우기 위한 추가 결론문을 생성하지 않는다.
- 같은 소재가 여러 섹션에 등장하더라도 각 섹션의 역할이 분명해야 한다.
- `더하는 말씀`의 소재가 `말씀의 핵심`보다 강한 주제로 보이지 않도록 한다.

단,

제목 → 말씀의 핵심 → 오늘의 적용 → 오늘의 기도처럼 **섹션 역할에 따라 같은 중심 주제가 기능적으로 이어지는 것은 허용한다.**

시각적 위계는 기본적으로 다음을 따른다.

**제목 > 말씀의 핵심 > 주요 섹션 제목 > 핵심어 > 본문 설명 > 보조 정보**

# 23. 최종 검수

이미지 생성 전에 내부적으로 다음을 확인한다.

## 내용

- 입력 MD의 의미가 정확히 유지되었는가?
- 원문에 없는 사건·신학적 의미·교훈을 추가하지 않았는가?
- 텍스트를 보기 좋게 만들기 위해 원문을 과도하게 재작성하지 않았는가?

## 상단

- 제목이 가장 강하게 보이는가?
- 성경본문이 한 번만 표시되는가?
- 제목과 대표 이미지 사이에 충분한 여백이 있는가?
- 대표 일러스트가 상단에 집중되어 있는가?
- 말씀의 길잡이가 바로 아래에서 넓은 문단형 카드로 자연스럽게 읽히는가?

## 대표 일러스트

- 이번 성경본문과 QT의 핵심을 기준으로 새롭게 설계한 장면인가?
- 이전 QT의 구도·배경·행동을 관성적으로 반복하지 않았는가?
- 대표 이미지가 이미 보여 준 내용을 본문에서 다시 큰 이미지로 반복하지 않았는가?

## 말씀의 길잡이

- 원문을 그대로 사용했는가?
- 번호형이나 단계형으로 바꾸지 않았는가?
- 자연스러운 줄바꿈 외에 불필요한 재작성은 없는가?

## 말씀을 따라

- 입력된 항목 수와 순서를 유지했는가?
- 4개 항목이면 1단 4열, 5개 항목이면 1단 5열을 우선 적용했는가?
- 각 카드가 번호 + 짧은 제목 + 설명으로 단순한가?
- 핵심어가 짧고 원문에 근거하는가?
- 추가 설명·장면 이미지가 없는가?
- 5열에서도 본문 글자 크기가 충분한가?

## 더하는 말씀

- 먼저 이번 QT 전체에서의 역할을 분석했는가?
- 사례 수에 따라 1개·2개·3개 중 실제 입력 구조를 유지했는가?
- 1개는 전체 폭의 `[이미지 | 제목·설명]` 좌우형인가?
- 2개는 동일 크기의 좌우 2카드이며 각 카드가 `[이미지 | 제목·설명]` 좌우형인가?
- 3개는 동일 크기의 3카드이며 각 카드가 `[상단 이미지 | 하단 제목·설명]` 세로형인가?
- 각 유형 안에서 카드 크기·이미지 비율·여백·화풍이 동일한가?
- 순차적 사례가 아니면 화살표를 사용하지 않았는가?
- 원문 내용이 중심인가?
- 소재 자체가 새로운 핵심 주제로 과도하게 강조되지 않았는가?
- 관계가 중요하지 않은데 관계도를 사용하지 않았는가?
- 장식용 대형 인물 이미지를 사용하지 않았는가?
- 보조 메시지가 원문과 말씀의 핵심에 직접 근거하는가?
- 같은 의미를 반복하는 추가 결론문이 없는가?

## 말씀의 핵심

- 원문을 유지했는가?
- 전체 QT의 중심 메시지가 분명한가?
- 더하는 말씀보다 시각적으로 분명한가?
- 제목보다 과도하게 강하지 않은가?

## 오늘의 적용

- 입력 원문을 유지했는가?
- 3개 항목이면 3분할 구조를 적절히 검토했는가?
- 핵심어 + 원문 설명 구조가 읽기 쉬운가?
- 불필요한 재작성이나 새 적용이 없는가?

## 오늘의 기도

- 입력 기도문을 유지했는가?
- 새 문장을 추가하지 않았는가?
- 글자가 충분히 큰가?

## 하단

- 관련 성구가 있으면 `본문과 함께 읽는 말씀`을 사용했는가?
- 관련 성구가 있는데 한 줄 메시지를 추가하지 않았는가?
- 관련 성구가 없을 때만 한 줄 메시지를 사용했는가?

## 전체 디자인

- 상단·중단·하단의 정보 밀도가 균형 잡혀 있는가?
- 이미지가 너무 많아 복잡하지 않은가?

# 26. 최종 핵심 원칙

반드시 다음을 기억한다.

> **내용을 레이아웃에 맞추지 않는다. 레이아웃을 내용에 맞춘다.**

> **상단은 제목·성경본문·대표 일러스트를 먼저 인식하게 하고, 말씀의 길잡이는 바로 아래에서 넓은 문단형 해설로 읽히게 한다.**

> **말씀의 길잡이는 원문 중심의 문단형 해설이고, 말씀을 따라는 번호 + 핵심어 + 설명의 항목형 구조이다. 두 섹션의 역할을 혼동하지 않는다.**

> **말씀을 따라는 실제 의미 단위에 따라 4개 또는 5개로 구성하며, 4개는 1단 4열, 5개는 1단 5열을 기본으로 한다.**

> **더하는 말씀은 사례 수에 따라 1~3개로 구성하며, 1개와 2개는 [이미지 | 제목·설명] 좌우형, 3개는 [상단 이미지 | 하단 제목·설명] 3열형을 사용한다.**

> **1개와 2개는 카드 높이를 낮춰 불필요한 세로 여백을 줄이고, 3개는 좁은 폭에서의 가독성을 위해 세로형 카드로 전환한다.**

> **대표 일러스트가 이미 보여 준 핵심 장면을 본문에서 큰 이미지로 반복하지 않는다.**

> **오늘의 적용과 오늘의 기도는 입력 원문을 유지하고, 시각 구조만 정돈한다.**

> **확정된 기본 골격을 반복 사용하되, 카드 수와 카드 내부 구조는 설교요약의 실제 내용에 맞게 가변적으로 적용한다.**

> **디자인을 위해 말씀을 바꾸지 않고, 공간을 채우기 위해 내용을 만들지 않으며, 이미지 수보다 정보 구조와 여백으로 완성도를 높인다.**

# 27. v7 확정 변경사항 요약

v7에서는 최근 검토를 통해 안정화된 인포그래픽 구조를 기본값으로 사용한다.

1. 신규 QT마다 A/B/C 구성안 선택을 반복하지 않고 확정 기본 골격을 우선 적용한다.
2. `말씀을 따라`는 실제 의미 단위에 따라 4개 또는 5개로 가변 구성한다.
3. `말씀을 따라` 4개는 1단 4열, 5개는 1단 5열을 기본으로 한다.
4. `더하는 말씀`은 사례 수에 따라 1~3개로 가변 구성한다.
5. `더하는 말씀` 1개는 전체 폭 단일 카드의 `[이미지 | 제목·설명]` 좌우형이다.
6. `더하는 말씀` 2개는 동일 크기 좌우 2카드이며 각 카드가 `[이미지 | 제목·설명]` 좌우형이다.
7. `더하는 말씀` 3개는 동일 크기 3카드이며 각 카드가 `[상단 이미지 | 하단 제목·설명]` 세로형이다.
8. 순차적 사례가 아니면 `더하는 말씀` 카드 사이에 화살표를 사용하지 않는다.
9. 저채도 파스텔, 굵은 고딕 제목, 절제된 이미지 면적, 컴팩트한 섹션 아이콘을 기본 스타일로 유지한다.
10. `오늘의 적용`과 `오늘의 기도`는 하단 좌우 2단을 기본으로 한다.
11. 관련 성구가 있으면 `본문과 함께 읽는 말씀`을 사용하고 한 줄 메시지는 생성하지 않는다.
12. 페이지 최하단의 AI 안내 영역은 생성 전부터 독립 공간으로 확보한다.
13. 사용자가 명시적으로 OK하기 전에는 이미지를 생성하지 않는다.
