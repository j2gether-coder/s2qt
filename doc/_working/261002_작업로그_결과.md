## 단계 A — 길이 (장년만)

```
Summary: 3-4 sentences, about 150-180 Korean characters
- 문장 수와 글자 수를 모두 지킨다. 한 문장을 길게 늘여 글자 수를 채우지 않는다.

Prayer: 3-4 sentences, about 120-150 Korean characters
- Structure: 경배 → 회개 → 감사 → 간구
  네 단계를 모두 담되 압축한다. 문장 수를 줄이려고 단계를 빼지 않는다.
  한 문장이 두 단계를 겸해도 좋다.
```

비장년(young_adult 4-5 / teen 3-4 / child 2-3)은 건드리지 않았습니다. md는 장년 전용입니다.

## 단계 B — 찬송가 프롬프트 4곳

| 위치 | 변경 |
|---|---|
| JSON 스키마 템플릿 | `"hymn": "새찬송가 456장"` → **`"{{hymn}}"`** |
| METADATA FIDELITY | hymn **조건부 규칙** 추가 (있으면 복사 / 비면 추천 / 반례 포함) |
| 필드 규칙 | 한 줄에 섞여 있던 두 지시를 지우고 FIDELITY를 가리키게 함 |
| 기본 프롬프트 | `Example:` → **`형식 예:`**, 값은 입력을 따르라고 명시 |

스키마 템플릿이 가장 중요했습니다. 모델에게 가장 강한 신호는 설명문이 아니라 **스키마 예시**이고,
거기 박힌 값이 456장이었습니다.

## 단계 C — 찬송가 코드 확정

```go
hymn := normalizeHymnText(req.Hymn)
```

`temp.json`에 LLM값이 들어가 **목록의 찬송과 주보의 찬송이 다를 수 있었습니다.**

시그니처가 `saveHistory(req, doc, hymn)`으로 늘었습니다. 안에서 다시 계산하면
`"찬송가:"` 접두어를 뗀 경우에만 두 곳이 갈립니다.

## 테스트 — 신규 10건

`service/hymn_and_length_test.go` **신규**.

```
TestBuildQTPromptJSON_AdultLengthRules               3-4문장 + 글자 수, 옛 5-6문장 없음
TestBuildQTPromptJSON_PrayerKeepsStructure           4단계 + "압축하되 빼지 않는다"
TestBuildQTPromptJSON_NonAdultLengthUnchanged        young_adult/teen/child 불변
TestBuildQTPromptJSON_HymnPlaceholderInSchema        스키마에 입력값 치환, 하드코딩 없음
TestBuildQTPromptJSON_HymnFidelityRule               조건부 규칙 존재
TestBuildQTPromptJSON_EmptyHymnLeavesPlaceholderBlank 빈 입력에서도 추천 지시 생존

TestStep1Save_EmptyHymnKeepsLLMRecommendation        화면 공백 → LLM 추천 유지
TestStep1Save_HymnNormalizedConsistently             "찬송가: " 접두어 제거
TestNormalizeHymnText_StripsPrefixes                 정규화 계약 고정
```

`llmJSON()`에 `hymn: llmHymn("새찬송가 456장")`을 추가했습니다. 없으면 "화면값이 LLM값을
이긴다"를 검증할 수 없습니다.

### 테스트를 한 번 틀렸고 고쳤다

`HymnPlaceholderInSchema`가 처음에 실패했습니다. 프롬프트 전체에서 `새찬송가 456장`을 찾았는데,
제가 METADATA FIDELITY에 넣은 **반례**(`✗ "hymn": "새찬송가 456장"`)에 걸린 것입니다.

반례는 있어야 할 자리에 있는 것이므로, 테스트가 **스키마 템플릿 블록만** 보도록 좁혔습니다
(`schemaTemplateBlock()`). 문제가 되는 것은 "프롬프트에 456장이 있는가"가 아니라
**"스키마 안에 베낄 값이 있는가"** 입니다.

### 단위 테스트로 덮지 않은 것

`Save()`가 정규화한 값을 `saveHistory`에도 넘기는지는 **DB가 필요해 단위 테스트로 확인하지
않았습니다.** 테스트 서비스는 `History == nil`이라 그 경로가 돌지 않습니다.
공유하는 정규화 계약만 고정하고, 나머지는 앱 확인 **H3**로 남겼습니다.
