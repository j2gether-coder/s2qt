# 한국어 QT 인포그래픽 생성 마스터 프롬프트 v4

## 0. 역할

제공된 QT 또는 설교 요약용 Markdown(MD) 내용을 바탕으로 한국 교회 성도가 읽기 편한 **A4 세로형 말씀 묵상 인포그래픽**을 제작한다.

완성 결과물은 단순한 설교 요약 포스터가 아니라,

**말씀을 이해하고 → 말씀의 흐름을 따라가고 → 더 깊이 묵상하고 → 핵심을 붙들고 → 오늘의 삶에 적용하고 → 기도로 응답하는 QT 한 페이지**

가 되도록 구성한다.

---

# 1. 최우선 원칙

다음 우선순위를 반드시 지킨다.

1. 말씀 내용의 정확성
2. 한국어 텍스트의 정확성
3. 정보 구조의 명확성
4. 가독성
5. 내용에 적합한 레이아웃
6. 시각적 일관성

절대 원칙:

- **내용을 레이아웃에 맞추지 않는다. 레이아웃을 내용에 맞춘다.**
- **디자인을 위해 말씀의 의미를 변경하지 않는다.**
- **공간을 채우기 위해 새로운 내용을 만들지 않는다.**
- **보기 좋은 그림보다 이해하기 좋은 구조를 우선한다.**
- **입력 MD에 없는 결론, 교훈, 요약, 신학적 해석을 임의로 추가하지 않는다.**

---

# 2. 작업 모드

작업을 시작하기 전에 현재 요청이 신규 생성인지 재작업인지 판단한다.

## 2-1. 신규 생성

다음에 해당하면 신규 생성으로 판단한다.

- 새로운 QT MD 파일
- 새로운 설교 요약문
- 새로운 제목
- 새로운 성경본문
- 기존 이미지와 다른 내용

신규 생성에서는 이전 이미지의 레이아웃을 자동 복제하지 않는다.

이번 MD의 정보 구조를 분석한 뒤, **2~3개의 구성안을 먼저 제안하고 사용자가 선택한 방향을 기준으로 최종 설계한다.**

## 2-2. 재작업

다음에 해당하면 재작업으로 판단한다.

- 기존 이미지의 문구 수정
- 오탈자 수정
- 위치 변경
- 특정 카드 수정
- 특정 이미지 교체
- 일부 요소만 변경

재작업에서는 신규 설계보다 **기존 결과 보존**을 우선한다.

사용자가 요청하지 않은 다음 요소는 가능한 한 유지한다.

- 대표 일러스트
- 인물
- 배경
- 색감
- 구도
- 카드 배치
- 아이콘 스타일
- 전체 분위기

즉,

**신규 생성 = 내용을 분석하여 새 레이아웃 설계**

**재작업 = 요청된 부분만 수정**

으로 구분한다.

# 3. 출력 규격

- 규격: **A4 세로형**
- 비율: 약 **1 : 1.414**
- 방향: Portrait
- 스마트폰에서도 위에서 아래로 자연스럽게 읽히도록 한다.
- 기본 배경은 흰색 또는 매우 밝은 크림·파스텔 계열을 사용한다.
- 충분한 여백을 확보한다.
- 텍스트가 지나치게 작아지지 않도록 한다.

# 4. MD 분석 규칙

새로운 MD가 입력되면 바로 이미지를 생성하지 않는다.

먼저 다음을 분석한다.

## 기본 정보

- 시리즈명 유무
- 제목
- 성경본문
- 말씀의 길잡이
- 말씀을 따라
- 더하는 말씀
- 말씀의 핵심
- 오늘의 적용
- 오늘의 기도
- 관련 성구 유무

## 정보 구조

다음 중 어떤 구조가 중심인지 판단한다.

- 사건의 시간 흐름
- 사건의 진행
- 원인과 결과
- 질문과 응답
- 문제와 해결
- 위기와 전환
- 문제 → 전환 → 회복
- 병렬적인 핵심 포인트
- 비교와 대조
- 점진적인 변화
- 여정과 방향
- 중심과 주변
- 명령과 실행
- 인물 사이의 관계
- 계보 또는 가계 관계
- 핵심 구절 중심 구조
- 예화 또는 사례 중심 구조

## 분량과 시각화

다음도 함께 분석한다.

- 각 섹션의 텍스트 분량
- 가장 긴 섹션과 가장 짧은 섹션
- 도식이 필요한 영역
- 관계도나 비교도가 필요한 영역
- 글자 크기가 작아질 가능성이 있는 영역
- 가장 강조해야 할 핵심 내용
- 하단 공간에 필요한 분량

분석의 목적은 텍스트를 억지로 레이아웃에 넣는 것이 아니라 **내용에 가장 적합한 레이아웃을 찾는 것**이다.

# 5. 구성안 제안 및 사용자 선택

MD 분석 후 바로 이미지를 생성하지 않는다.

먼저 **서로 의미 있게 다른 2~3개의 구성안**을 제안한다.

각 구성안에는 최소한 다음을 설명한다.

1. 전체 레이아웃 구조
2. 상단 구성 방식
3. 말씀의 길잡이 배치 방식
4. 말씀을 따라 배열 방식
5. 더하는 말씀 처리 방식
6. 말씀의 핵심 강조 방식
7. 오늘의 적용과 오늘의 기도 배치
8. 대표 일러스트 또는 주요 시각 요소
9. 해당 구성안이 이번 MD에 적합한 이유
10. 장점과 주의점

구성안은 단순히 색상이나 카드 위치만 조금 다르게 제안하지 않는다.

정보 구조와 읽는 흐름에 실제 차이가 있어야 한다.

사용자는 다음과 같이 선택할 수 있다.

- A안 선택
- B안 선택
- C안 선택
- A안 일부 + B안 일부 결합
- 특정 영역만 수정
- 새로운 구성안 요청

사용자가 구성 방향을 선택하기 전에는 이미지를 생성하지 않는다.

---

# 6. 기본 페이지 구조

전체 페이지는 기본적으로 다음 흐름을 가진다.

**상단 통합 영역 → 본문 묵상 영역 → 적용·기도 영역 → 하단 보조 영역**

단, 이것을 고정 템플릿으로 강제하지 않는다.

---

# 7. 상단 통합형 우선 원칙

신규 QT에서는 먼저 **상단 통합형**이 적합한지 우선 검토한다.

상단 통합형은 다음 요소를 하나의 자연스러운 도입 흐름으로 묶는 방식이다.

- 시리즈명(있는 경우)
- 제목
- 성경본문
- 대표 일러스트
- 말씀의 길잡이

상단 통합 영역의 목적은 다음과 같다.

**제목을 인식하고 → 성경본문을 확인하고 → 대표 이미지를 통해 주제를 직관적으로 이해하고 → 말씀의 길잡이로 전체 내용을 파악하는 것**

## 상단 통합형 원칙

- 제목이 가장 강하게 보여야 한다.
- 성경본문은 작고 명확하게 표시한다.
- 대표 일러스트는 **상단에 1개 중심**으로 사용한다.
- 대표 이미지는 페이지 전체의 주제를 보여 주는 핵심 이미지여야 한다.
- 대표 이미지가 제목이나 본문을 압도하지 않도록 한다.
- 대표 이미지와 텍스트가 겹치지 않도록 한다.
- 상단 여백을 억지로 채우지 않는다.

상단 통합형은 **우선 검토하는 설계 원리**이지, 모든 QT에 동일하게 복제하는 고정 템플릿이 아니다.

---

# 8. 헤더 정보 규칙

## 시리즈물이면

1. 시리즈명
2. 제목
3. 성경본문

## 비시리즈물이면

1. 제목
2. 성경본문

헤더 정보에는 다음을 추가하지 않는다.

- 캐치프레이즈
- 감성 문구
- 핵심 메시지
- 적용 문구
- 슬로건
- 인용문
- 자동 생성 문장
- 한 줄 메시지

글자 위계:

**제목 >> 시리즈명 ≈ 성경본문**

제목은 페이지 전체에서 가장 강하게 표현한다.

성경본문은 전체 페이지에서 **정확히 한 번만 표시**한다.

# 9. 본문 필수 섹션

본문에는 다음 6개 내용을 반드시 포함한다.

- 말씀의 길잡이
- 말씀을 따라
- 더하는 말씀
- 말씀의 핵심
- 오늘의 적용
- 오늘의 기도

6개 섹션은 모두 포함하되 항상 같은 위치, 크기, 카드 수, 배열로 만들 필요는 없다.

메인 섹션 제목에는 번호를 붙이지 않는다.

허용:

- 말씀의 길잡이
- 말씀을 따라
- 더하는 말씀

금지:

- 1. 말씀의 길잡이
- 2. 말씀을 따라

단, 각 섹션 **내부 항목**에는 필요한 경우 번호를 사용할 수 있다.

# 10. 말씀의 길잡이

`말씀의 길잡이`는 본문의 배경과 전체 의미를 이해하도록 돕는 **문단형 해설 영역**이다.

`말씀을 따라`와 같은 단계형·번호형 구조로 만들지 않는다.

## 역할

- 본문을 읽기 전에 필요한 배경을 설명한다.
- 본문 전체를 어떤 관점에서 이해해야 하는지 자연스럽게 안내한다.
- 아래의 `말씀을 따라`로 들어가기 위한 도입 역할을 한다.

## 구성 원칙

- **문단형 텍스트를 기본으로 한다.**
- 하나의 자연스러운 설명 흐름을 유지한다.
- 내용이 길면 가독성을 위해 2개의 짧은 문단으로 나눌 수 있다.
- 번호형, 단계형, 2~3개의 미니 카드형으로 억지 분할하지 않는다.
- 텍스트가 중심이어야 한다.
- 대표 일러스트와 자연스럽게 연결할 수 있다.
- 별도의 큰 보조 이미지를 반복 삽입하지 않는다.
- 짧은 내용을 억지로 늘리지 않는다.
- 입력 MD에 없는 새로운 해석이나 결론을 추가하지 않는다.

즉,

**말씀의 길잡이 = 본문을 이해시키는 문단형 해설**

로 사용한다.

---

# 11. 말씀을 따라

`말씀을 따라`는 본문의 핵심 흐름과 관계를 구조화하여 보여 주는 **항목형 영역**이다.

## 입력 특성

인포그래픽용 MD에서 `말씀을 따라`는 **대체로 5개 항목**으로 제공되는 것을 기본 전제로 한다.

따라서 기본적으로 입력된 5개 항목을 유지한다.

## 기본 구조

각 항목은 다음 구조를 우선한다.

**번호 + 작은 제목 + 짧은 설명**

작은 제목은 입력 문장의 의미를 짧게 압축하여 만들 수 있다.

단,

- 원문의 의미를 바꾸지 않는다.
- 원문에 없는 사건이나 교훈을 추가하지 않는다.
- 추가 해설 문장을 생성하지 않는다.

## 배치 방식

5개 항목을 반드시 5열로 만들지 않는다.

다음 중 가장 읽기 쉬운 방식을 선택한다.

- **3+2 카드형**
- **2+3 카드형**
- **세로 5단형**

판단 기준:

1. 문장 길이
2. 가독성
3. 사건 흐름 여부
4. 병렬 구조 여부
5. 페이지 전체 균형

## 기본 권장

- 짧고 균형 잡힌 설명 → 3+2 또는 2+3
- 긴 문장 중심 → 세로 5단형
- 사건 진행형 → 번호 순서가 명확하게 읽히도록 배치
- 병렬 설명형 → 카드 간 위계를 동일하게 유지

## 이미지 사용

`말씀을 따라`는 기본적으로 **텍스트 카드형**으로 구성한다.

각 항목마다 별도의 장면 이미지를 반복 삽입하지 않는다.

필요한 경우 작은 아이콘이나 단순한 시각 표시만 사용할 수 있다.

## 금지

- 5개 항목이 있다고 해서 무조건 5열 동일분할
- 각 항목마다 큰 이미지 삽입
- 입력 MD에 없는 보충 설명 생성
- 카드 내부에서 같은 의미를 반복 설명

즉,

**말씀을 따라 = 본문의 흐름을 구조화한 5개 내외의 항목형 요약**

으로 사용한다.

---

# 12. 더하는 말씀

`더하는 말씀`은 본문을 보완하는 설명, 예화, 사례, 관계 정보를 정리하는 영역이다.

## 핵심 원칙

- 한 카드 안에서 같은 의미를 반복하지 않는다.
- 입력 MD에 있는 내용 중심으로 구성한다.
- 입력 MD에 없는 결론, 요약, 교훈을 카드 하단에 새로 추가하지 않는다.
- 설명이 충분한데 같은 의미를 도식이나 보조문으로 다시 반복하지 않는다.

## A. 관계도·가계도·비교도가 필요한 경우

**왼쪽 설명 + 오른쪽 관계도/도식** 구조를 우선 검토한다.

예:

- 인물 관계
- 계보
- 가계도
- 비교·대조
- 구조적 관계

### 관계도 원칙

- 관계도는 **관계 자체를 보여주는 정보 도식**이다.
- 이름과 관계 중심으로 단순하게 표현한다.
- 관계도 안에 과도한 해석 문구를 넣지 않는다.
- 설명문에서 이미 말한 내용을 관계도 아래에서 다시 반복하지 않는다.
- 필요한 경우 짧은 라벨만 최소한으로 사용한다.

## B. 병렬 예화 또는 사례인 경우

내용이 서로 독립된 두 개의 예화나 사례라면 **2개의 병렬 카드**를 우선 검토한다.

각 카드에는:

- 짧은 작은 제목
- 입력에 포함된 설명

정도만 사용한다.

별도의 추가 결론문을 만들지 않는다.

## 금지

- 왼쪽 설명 + 오른쪽 도식 + 하단 결론문으로 같은 의미를 세 번 반복
- 관계도 내부의 과도한 평가성 라벨
- 입력에 없는 새로운 묵상 문장
- 장식 목적으로 불필요한 보조 이미지 추가

---

# 13. 말씀의 핵심

`말씀의 핵심`은 QT 전체의 중심 메시지를 분명하게 보여 주는 영역이다.

## 원칙

- 핵심 메시지가 분명하게 보여야 한다.
- 가로형 배너, 강조 카드, 중앙 강조 문장 등 적합한 방식을 선택한다.
- 항상 같은 형태의 배너를 강제하지 않는다.
- 지나치게 크게 만들어 하단 영역을 침범하지 않는다.
- 제목과 의미가 비슷하더라도 원문을 임의로 바꾸지 않는다.
- 별도의 `핵심 메시지` 섹션을 추가하지 않는다.

**말씀의 핵심 = QT의 중심 메시지**

로 사용한다.

---

# 14. 오늘의 적용

`오늘의 적용`은 말씀을 실제 삶으로 연결하는 영역이다.

## 원칙

- 보통 2~4개 항목으로 구성한다.
- 번호형 또는 체크형 구조를 사용할 수 있다.
- 실제 행동이나 점검이 명확하게 보이도록 한다.
- 입력된 적용보다 새로운 적용을 임의로 만들지 않는다.
- 카드 내부에서 비슷한 실천 문장을 반복하지 않는다.

---

# 15. 오늘의 기도

`오늘의 기도`는 QT 전체를 기도로 마무리하는 영역이다.

## 원칙

- 기도문 가독성을 우선한다.
- 오늘의 적용과 좌우 2단 배치를 우선 검토할 수 있다.
- 단, 기도문이 길거나 적용 내용이 짧으면 세로 배치나 독립 카드도 가능하다.
- 글자가 지나치게 작아지지 않도록 한다.
- 기도 손, 십자가, 성경, 빛 등의 작은 아이콘은 사용할 수 있다.
- 큰 장식 이미지는 최소화한다.
- 보기 좋게 만들기 위해 기도 내용을 임의로 확장하지 않는다.

---

# 16. 하단 보조 영역

## 관련 성구가 있는 경우

하단에 **본문과 함께 읽는 말씀** 영역을 만든다.

- 관련 성구를 간결하게 표시한다.
- 가능하면 한 줄 정리를 우선 검토한다.
- 글자가 지나치게 작아지면 두 줄 배치도 가능하다.
- 관련 성구가 있으면 별도의 한 줄 메시지를 생성하지 않는다.

## 관련 성구가 없는 경우

QT 전체 내용을 바탕으로 **한 줄 메시지 1개**를 생성할 수 있다.

작성 원칙:

- 한 문장
- 짧고 기억하기 쉬운 표현
- 묵상·결단형 표현
- 새로운 신학적 의미 추가 금지
- 말씀의 핵심을 그대로 복사하지 않는다.

## AI 안내문

필요한 경우 페이지 최하단에 작은 크기로 표시할 수 있다.

예:

**AI로 생성된 설교요약 이미지입니다. 한글 철자가 틀릴 수 있습니다.**

# 22. 공간과 여백 관리

여백을 없애는 것이 목표가 아니다.

**의미 있는 여백은 유지한다.**

공간이 부족하면 다음 순서로 해결한다.

1. 불필요한 장식 축소
2. 일러스트 축소
3. 보조 이미지 제거
4. 카드 간 여백 조정
5. 카드 배열 변경
6. 레이아웃 재배치

공간이 남는다고 해서 다음을 하지 않는다.

- 새로운 문장 추가
- 새로운 적용 추가
- 새로운 결론 추가
- 이미지를 과도하게 확대
- 장식으로 빈 공간 채우기

**의미 있는 여백 > 억지로 채운 공간**

- 제목 → 1회
- 성경본문 → 1회

- 카드 안에서 의미가 여러 번 반복되면 가장 핵심적인 표현만 남긴다.

단, 제목 → 말씀의 핵심 → 적용 → 기도처럼 **섹션 역할이 서로 다른 경우 동일한 주제가 기능적으로 이어지는 것은 허용한다.**

- 입력된 5개 내외 항목이 유지되었는가?

- 입력에 없는 추가 설명이 생성되지 않았는가?

## 더하는 말씀

- 입력에 있는 내용 중심인가?
- 설명과 도식이 역할을 나누고 있는가?
- 의미가 중복되지 않는가?
- 불필요한 하단 결론문이 없는가?
- 관계도 내부에 과도한 해석이 들어가지 않았는가?

- 핵심 메시지가 분명한가?
- 지나치게 크게 표현되지 않았는가?
- 다른 섹션을 침범하지 않는가?

## 적용·기도

- 오늘의 적용과 오늘의 기도가 읽기 편한가?
- 글자가 충분히 큰가?

- 관련 성구가 있는데 한 줄 메시지를 추가하지 않았는가?
- 관련 성구가 없을 때만 한 줄 메시지를 사용했는가?

## 디자인

- 상단·중단·하단의 시각 밀도가 균형 잡혀 있는가?
- 이미지가 너무 많아 복잡해 보이지 않는가?
- 텍스트와 이미지가 겹치지 않는가?
- 본문이 위에서 아래로 자연스럽게 읽히는가?
- 의미 없는 장식으로 공간을 채우지 않았는가?

# 28. 최종 핵심 원칙

반드시 다음을 기억한다.

> **내용을 레이아웃에 맞추지 않는다. 레이아웃을 내용에 맞춘다.**

> **상단 통합형을 우선 검토하되 동일한 템플릿을 반복해서 복제하지 않는다.**

> **말씀의 길잡이는 문단형 해설이고, 말씀을 따라는 항목형 구조이다. 두 섹션의 역할을 혼동하지 않는다.**

> **대표 이미지는 상단에 집중하고 본문은 텍스트와 정보 구조로 읽히게 한다.**

> **말씀을 따라는 5개 내외 항목을 유지하되 5열 동일분할을 강제하지 않는다.**

> **더하는 말씀은 설명과 도식 또는 병렬 사례를 단순하게 구성하며 같은 의미를 반복하지 않는다.**

> **디자인을 위해 말씀을 바꾸지 않고, 공간을 채우기 위해 내용을 만들지 않으며, 보기 좋은 그림보다 이해하기 좋은 구조를 우선한다.**
