## 1. 착수 전 확인된 사실

### 1-1. DB와 재작업은 손댈 것이 없다

`qt_result_json`이 **LLM 원본 전문**을 보관하므로 `metadata.series`가 자동으로 저장·복원됩니다. `history_master`에는 컬럼을 추가하지 않고 **`title` 라벨에만 합쳐 넣습니다**(`InitSQLite`에 `ALTER` 경로가 없어 컬럼 추가는 비용이 큼).

`parseFlatQTStep2JSON` 경로(구버전 이력)는 `series`가 없어 빈 값이 되며, **그대로 정상 동작**합니다.

### 1-2. 템플릿에는 CSS 파일이 없다

`var/template/*`에는 `manifest.json`만 있습니다. 템플릿은 Go 상수와 `var/conf/*.css`를 물려받으므로, **CSS는 4곳만** 손보면 전 산출물에 적용됩니다.

### 1-3. PDF/PNG는 HTML 조각을 그대로 렌더한다

`wrapHTMLForPDF(fragment, ...)` / `wrapHTMLForTemplatePDF(content, ...)` 모두 조각을 감싸기만 합니다. **CSS만 있으면 새 블록이 표시됩니다.**

단, `removeKnownTopLevelBlocks()`가 `qt-title`/`qt-subbox`만 제거하므로 패턴을 한 줄 추가해야 합니다. 이 함수가 만드는 JSON은 곧 삭제되는 부수 산출물이라 실제 영향은 없지만, 빠뜨리면 나중에 원인 찾기 어려운 오염이 됩니다.

## 3. 단계별 작업 지시

각 단계 종료 시 **빌드가 통과**하도록 구성했습니다.

### 단계 A — 입력 경로 (0.5일)

**목표**: 화면에서 받은 시리즈를 프롬프트 조립까지 흘려보낸다.

- **A-1** `mainWorkspace.js` 기본정보 2열 그리드에 **시리즈**를 추가합니다. **`required-mark`를 붙이지 않습니다**(선택 항목).
  - 배치: **제목 바로 앞**이 자연스럽습니다. 시리즈 → 제목 → 본문 성구 → 찬송 → 설교자 → 교회명 → 설교일
  - 헤더 문구 `제목과 본문 성구는 필수이며, 그 외 항목은 선택입니다.`는 그대로 유효합니다
  - `id="series-input"`, 값 수집은 기존 필드와 같은 방식
- **A-2** `appState.js`의 `basicInfo` 기본값에 `series: ""`를 넣습니다. 기본정보 저장/복원 경로도 함께 확인하십시오.
- **A-3** `types.go`의 네 구조체에 필드를 추가합니다. **JSON 태그를 통일**하십시오.
  ```go
  Series string `json:"series"`
  ```
  대상: `QTMeta` · `LLMPrepareRequest` · `QTStep1SaveRequest` · `QTStep2Data`
- **A-4** `bindQTStep1.js`의 `buildLLMRequest()`에 `series: info.series || ''`를 추가합니다. 결과저장은 이 함수를 그대로 쓰므로 자동으로 전달됩니다.
- **A-5** `app.go`의 `BuildQTPrompt`에서 `meta.Series = strings.TrimSpace(req.Series)`를 채웁니다. `pipeline_service.go`의 `RunLLMPrepare`도 같은 자리에 추가하십시오(**API 경로 누락 주의**).

**완료 조건**: 시리즈를 입력하고 프롬프트를 생성하면 프롬프트 안에 시리즈명이 보인다.

### 단계 B — 프롬프트 (0.25일)

- **B-1** `defaultQTPromptJSONSchema`의 metadata 예시에 한 줄 추가.
  ```
  "series": "{{series}}",
  ```
  `"title"` **바로 앞**에 두어 읽는 순서를 맞춥니다.
- **B-2** METADATA FIDELITY 목록에 `series`를 추가합니다. 지난 작업에서 만든 블록에 필드명만 얹으면 됩니다.
  ```
  preacher / church_name / sermon_date / source_url / month_name / month_accent / series
  ```
- **B-3** 제목 규칙에 한 줄 추가합니다. **비장년은 LLM이 제목을 새로 짓기 때문에 필요합니다.**
  ```
  - series가 주어진 경우, 그 시리즈명을 title에 반복하지 않는다.
    title은 이번 회차의 내용만 담는다.
    ✗ "[QT] 본받고 싶은 교회(1) 데살로니가서를 시작하며"
    ✓ "[QT] 데살로니가서를 시작하며"
  ```
- **B-4** `BuildQTPromptJSON()`의 `strings.NewReplacer`에 `"{{series}}", meta.Series`를 추가합니다.

**완료 조건**: adult/teen 모두 프롬프트에 `series`가 보이고, 시리즈가 비면 `""`로 치환된다.

### 단계 C — temp.json 왕복 + Step2 (0.5일)

- **C-1** `qtstep1_service.go`의 `writeTempJSON`에서 **요청값으로 덮어씁니다.**
  ```go
  // series는 LLM이 더할 정보가 없는 순수 사용자 입력이므로,
  // LLM 출력을 신뢰하지 않고 화면 입력값으로 확정한다(날조 차단).
  if qt.Metadata == nil {
      qt.Metadata = map[string]any{}
  }
  qt.Metadata["series"] = strings.TrimSpace(req.Series)
  ```
  > `writeTempJSON`이 현재 `req`를 받지 않으므로 **시그니처에 series를 넘겨야 합니다.**
- **C-2** `qtstep2_service.go`의 `Load()`에 `out.Series = getStringFromMap(doc.Metadata, "series")`를 추가합니다.
- **C-3** 같은 파일 `Save()`의 metadata 맵에 `"series": strings.TrimSpace(req.Series)`를 추가합니다. **빠뜨리면 Step2 저장에서 시리즈가 유실됩니다** — `QTSectionDoc`을 통째로 새로 만드는 구조이기 때문입니다.
- **C-4** `qtStep2.js`에 시리즈 입력 칸을 추가합니다. 제목 칸과 같은 형태로, 제목 바로 앞에 둡니다.
- **C-5** `bindQTStep2.js` 세 곳을 손봅니다.
  - `buildStep2Payload()` — `series: getValue('series').trim() || (basicInfo.series || loadedMeta.series || '').trim()`
  - `loadStep2Data()` — `setValue('series', ...)`
  - `setLoadedStep2Meta()` / `getLoadedStep2Meta()` — `series` 포함

**완료 조건**: Step1 저장 → Step2 진입 시 시리즈가 채워져 있고, Step2 저장 후 temp.json에 `metadata.series`가 남아 있다.

### 단계 D — 산출물 렌더 + CSS (0.75일)

- **D-1** `buildQTStep2HTML`에 블록을 추가합니다. **비면 줄 자체를 넣지 않습니다.**
  ```go
  seriesText := strings.TrimSpace(req.Series)
  seriesHTML := ""
  if seriesText != "" {
      seriesHTML = `<div class="qt-series">` + escapeHTML(seriesText) + `</div>`
  }
  ```
  `<div class="qt-wrap">` 다음, `qt-title` **앞**에 넣습니다.
- **D-2** `blog_service.go` — `blogMetadata` 구조체에 `Series string \`json:"series"\``를 추가하고, `buildBlogBody`에서 같은 블록을 씁니다.
- **D-3** `infographic_service.go` — `RenderInfographicMD(data, title, bibleText)`에 `series`를 추가합니다. 마크다운에는 **제목 위 한 줄**로 넣습니다.
  ```markdown
  본받고 싶은 교회(1)

  # 데살로니가서를 시작하며
  ```
  시리즈가 비면 그 줄과 뒤따르는 빈 줄을 **모두** 생략합니다. 호출부(`qtstep1_service.go`, `history_service.go`)도 함께 고쳐야 합니다.
- **D-4** **CSS 4곳**에 규칙을 추가합니다. `qt-title`이 `border-bottom`을 갖고 있으므로 시리즈는 그 **위**에 놓입니다.

  ```css
    text-align: center;
    color: var(--qt-title);
    font-size: 13px;      /* qt-title 대비 작게. pdf는 12px */
    font-weight: 600;
  ```

  | 파일 | 위치 |

  | `var/conf/style_qt_pdf.css` | `.qt-title`(:62) 앞 |
  | `service/pdf_service.go` | `.qt-title` 규칙 2곳(:323, :692) 각각의 앞 |

- **D-5** `pdf_service.go`의 `removeKnownTopLevelBlocks()` 패턴 목록에 한 줄 추가합니다.


```
  → infographic.md 첫 줄이 시리즈, 그다음 "# 데살로니가서를 시작하며"

  → 산출물에 시리즈 줄 없음 (여백도 늘지 않음)
  → 작업내역 제목이 예전과 동일 (구분자 없음)

[T3] LLM 날조 방어

  → temp.json에는 화면 입력값이 들어감

[T4] 비장년 제목
  teen으로 시리즈 포함 실행
  → LLM이 지은 제목에 시리즈명이 반복되지 않음

[T5] 재작업
  T1의 이력을 재작업 → 시리즈가 복원되고 md도 다시 만들어짐

[T6] 구버전 이력
  9/5 이전 이력 재작업 → 오류 없음, 시리즈 없이 정상 진행

  var/temp/ 에 blog.html · infographic.md 를 남겨 둔 상태에서
```

## 5. 주의사항

1. **단계 C-3(Step2 Save)을 빠뜨리기 쉽습니다.** `Save()`가 `QTSectionDoc`을 새로 조립해 덮어쓰므로, metadata 맵에 넣지 않으면 Step2 저장 한 번에 시리즈가 사라집니다. `support_scriptures_full`이 같은 이유로 한 번 유실됐던 전례가 있습니다.
2. **단계 A-5의 API 경로**(`pipeline_service.go`)를 빠뜨리면 수동 붙여넣기에서만 동작합니다. 지난 작업에서도 같은 함정이 있었습니다.
3. **CSS는 Go 상수와 `var/conf/*.css` 양쪽**을 갱신해야 합니다(D-4).
4. `RenderInfographicMD`의 시그니처가 바뀌므로 **호출부 2곳**(`qtstep1_service.go`, `history_service.go`)과 테스트를 함께 고쳐야 합니다.
5. Wails 바인딩은 구조체 필드만 늘어나므로 **인자 개수가 그대로**입니다. 그래도 `wails generate module`로 `models.ts`를 갱신해 두십시오.
6. 구분자 ` — `는 **em dash**입니다. 소스에 직접 넣지 말고 상수로 두면 나중에 바꾸기 쉽습니다.
