# S2QT Infographic Style Guide

Version: 1.0
Last Updated: 2026-07-22

---

# 목적

본 문서는 S2QT 프로젝트의 QT 인포그래픽 제작 기준을 정의한다.

목표는

- 말씀의 흐름을 명확하게 전달하고
- 모바일과 인쇄 모두에서 읽기 쉽고
- 모든 인포그래픽의 품질을 일정하게 유지하는 것이다.

---

# 기본 원칙

## 1. 가독성 우선

화려한 디자인보다
읽기 쉬운 디자인을 우선한다.

우선순위

1. 내용
2. 구조
3. 가독성
4. 디자인

---

## 2. 말씀 중심

"설교"라는 표현보다

항상

**"말씀"**

중심의 표현을 사용한다.

예)

설교 흐름 → 말씀을 따라

설교 핵심 → 말씀의 핵심

설교 적용 → 오늘의 적용

설교 정리 → 말씀의 길잡이

# 말씀을 따라 구성

가능하면

3개의 큰 흐름으로 구성한다.

예)

① 문제 인식

↓

② 하나님의 말씀

↓

③ 삶의 적용

또는

① 죄

↓

② 회개

↓

③ 회복

# 문장 작성 기준

긴 문장은 줄인다.

한 문단

3줄 이하

한 Bullet

20자 내외

한 카드

최대 5줄

가능하면

명사형보다

자연스러운 문장으로 작성한다.

모두

---

# 말씀의 핵심

각 흐름마다

하나의 핵심 문장만 사용한다.

예)

평강은

환경이 아니라

하나님과의 관계에서 시작됩니다.

---

# 오늘의 적용

질문 형식 권장

예)

✔ 나는 평안을 주시는 하나님을 붙들고 있는가?

✔ 내 안의 우상은 무엇인가?

✔ 하나님께 순종하고 있는가?

5개 내외

---

# 오늘의 기도

150~250자 권장

너무 길게 작성하지 않는다.

---

# 이미지 생성 규칙

인포그래픽 생성 후

반드시

전체 텍스트를 검수한다.

확인 항목

□ 맞춤법

□ 띄어쓰기

□ 성경구절

□ 장절

□ 인명

□ 한글 깨짐

예)

시힘 → 시험

샐롬 → 샬롬

거룩하신 → 거룩하신

---

# 품질 체크리스트

□ 제목 오탈자 없음

□ 성경 본문 정확

□ 말씀 흐름이 자연스러움

□ 핵심 문장 명확

□ 적용이 말씀과 연결됨

□ 기도가 적용과 연결됨

□ 글자가 너무 작지 않음

□ 모바일에서도 읽을 수 있음

□ 인쇄 시 깨지지 않음

□ 한글 OCR 오류 없음
